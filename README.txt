Spotify-Styled Music Player - README

📁 Technologies Used:
- HTML5
- CSS3 (Dark theme inspired by Spotify)
- JavaScript (Vanilla JS + jsmediatags for metadata parsing)

✅ Features Implemented:
- Play/Pause, Seek, and Volume control
- Dynamic Playlist (upload and play local files)
- Display of Song Title, Artist, and Album
- Volume icon changes dynamically
- Responsive layout for desktop and mobile
- Auto-play next track when current song ends

🔧 How to Use:
1. Open `index.html` in a modern web browser.
2. Click "Choose Files" to upload audio files (MP3).
3. Click "Add to Playlist".
4. Click a song to play. Use controls for play, pause, next, etc.

📝 Notes:
- Metadata like Artist/Album is fetched using the `jsmediatags` library.
- Works offline with local files (no server needed).
